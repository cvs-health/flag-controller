# Security Policy

## Supported Versions

This repository does not currently publish versioned releases. Security reports may be submitted for the source code in this repository. If the project begins publishing releases, this section will be updated to identify supported versions and security-fix coverage.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests. Reports are handled privately so maintainers can investigate and coordinate a fix before public disclosure.

To report a vulnerability privately, email [cormick.white@cvshealth.com](mailto:cormick.white@cvshealth.com).

Please include as much of the following information as possible:

- A description of the vulnerability and its potential impact
- Affected versions, commit, or branch, if known
- Steps to reproduce the issue and any proof-of-concept
- Relevant logs, configuration, or source paths (please do not include secrets or personal data)
- Any suggested mitigations or fixes

### Response and Coordinated Disclosure

- We will acknowledge receipt within **72 hours**.
- Within **7 calendar days**, we will provide an initial assessment or an update on the investigation and next steps.
- We will work with the reporter to validate the issue, assess affected versions and severity, and coordinate a fix and disclosure timeline. Response and remediation timing may vary with severity, complexity, and release requirements; we will provide updates if timelines change.
- Please allow maintainers a reasonable opportunity to investigate and prepare a fix before publicly disclosing the issue. We will coordinate publication with the reporter when practical and publish an advisory with affected versions and mitigation or upgrade guidance when available.

This policy applies to the Flag Controller source code and the components maintained in this repository.
