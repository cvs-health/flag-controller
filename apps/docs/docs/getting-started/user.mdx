In order to start using Flag Controller:

1. **[Create or join a team](../guides/user-interface/teams/management)**

2. **[Create an application](../guides/user-interface/applications/management#creation)**

   An application owns your feature flags and segments, and is itself owned by a team. Reference the applications guide for everything else you can do with one.

3. **[Install the OpenFeature SDK and configure a Provider](../guides/providers)**

   [OpenFeature](https://openfeature.dev/) is at the foundation of Flag Controller. OpenFeature is an open specification that provides a vendor-agnostic, community-driven API for feature flagging. Choose the [OpenFeature Provider](https://openfeature.dev/ecosystem?instant_search%5BrefinementList%5D%5Btype%5D%5B0%5D=Provider) for your programming language and configure it to connect to your flagd instance.

4. **[Create a feature flag](../guides/user-interface/feature-flags/creation)**

   There are a number of different kinds of feature flags, each of which allow you to handle features in various ways based on your choosing.

5. **[Toggle your feature flag](../guides/user-interface/feature-flags/management#environment-actions)**

   They grow up so fast - toggle that thing on and watch your feature shine :star2:
