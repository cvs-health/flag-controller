# Welcome to the Flag Controller docs

_Flag Controller is built with [OpenFeature](https://openfeature.dev/), and allows you to enable or disable a project’s feature without modifying the source code or requiring a redeploy._

## What are Feature flags?

Feature flag (feature toggles, or feature flippers) is a software development tool that enable teams to turn functionalities on or off to safely test in production by separating code deployment from feature release and only ship new features to users when they are ready. This reduces risk by decoupling production deployment from userbase deployment.

## Is Flag Controller right for my project?

Feature flags are implemented in code through the use of an open source library, [OpenFeature](https://openfeature.dev/), and require an engineering team to configure them within the application. However, that does not mean that they are limited to engineering teams. The toggling and rule setting can be picked up and be managed by anyone, including Product Managers to UX peeps.

## Why should I use Flag Controller?

### Release anytime

Feature flags make releases easier by providing a controlled and gradual rollout of new features. Instead of deploying all changes at once, feature flags allow you to enable or disable specific features on the fly, giving you the flexibility to test and iterate in real-time. This reduces the risk of bugs or performance issues impacting all users and enables a smoother release process, ensuring a seamless user experience while maintaining the ability to quickly respond to any issues that may arise.

### Target your users

User targeting with feature flags offers a multitude of benefits, including the ability to deliver personalized experiences to specific user segments, gather valuable feedback from targeted users, and mitigate risks by gradually rolling out new features to a subset of users, ensuring a smooth and successful deployment. This targeted approach empowers businesses to optimize user engagement, increase conversion rates, and make data-driven decisions for continuous improvement.

### It's not just for developers

  Product managers and QA teams can use feature flags to manage rollouts and turn
  functionality on and off as needed. Any type of users can leverage feature flags
  to gain visibility into what is happening in development, check how new features
  are being tested with users, or create and enforce governance and standardization
  .
