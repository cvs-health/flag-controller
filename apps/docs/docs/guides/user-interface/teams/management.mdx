From the Teams page, you can create and remove teams. From a team’s details page, you can manage its members.

## Creating a team

1. Open **Teams** from the main navigation.
2. Select **Create team**.
3. Enter a unique team name.
4. Select **Create team**.

Team names cannot be changed after creation.

After creating a team, add yourself as a member if you need to access it. Creating the team does not automatically add you as a team member, but you can add yourself from the team’s Members tab.

## Adding team members

1. Open the team details page.
2. Select the option to add members.
3. Select one or more users from the list.
4. Confirm the selection.

Only users available in the member picker can be added, including yourself. Team membership determines who can perform management actions for the team and its resources, such as creating, editing, or deleting them.

## Removing a team member

1. Open the team details page.
2. Find the member in the members list.
3. Select the member removal action.
4. Confirm the removal.

Removing a member removes their association with the team. It does not delete the user account.

## Removing a team

You can remove a team from the Teams page or from the team details page. A team cannot be removed while it has applications associated with it.
