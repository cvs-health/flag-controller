The Teams page is the starting point for finding teams available in the system.

Each row in the teams table includes:

- The team name, which links to the team details page
- The applications associated with the team, which link to their application details
- Actions for managing the team, including removing it

## Finding a team

Open **Teams** from the main navigation. Browse the teams in the table and select a team name to view its details. Use the table pagination to move through the available teams.

If you do not see a team, check the table pagination. Once you find the team, add yourself as a member from the team details page to create and manage resources for it, such as applications and feature flags.

## Team details

The team details page provides access to the team’s:

- Applications
- Members
- Activity log

You can also use the team actions to remove the team when you have permission to do so.
