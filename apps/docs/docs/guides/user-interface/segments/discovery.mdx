---
title: Discovery
---

Segments are viewable through the 'Segments' page. The list displays all segments which are related to you by default based on the application that owns the segment.

Each of the segments in the list includes:

- The segment key which directs you to the segment details
- The application that owns the feature flag which directs your to the application details

You can use the search field to search for any segments which are or are not related to you.
