Applications are viewable through the 'Applications' page. Unlike the flag and segment lists, this page only displays the applications which are related to you through your team membership.

Each of the applications in the list includes:

- The application name which directs you to the application details
- The team which owns the application which directs you to the [team details](../teams/discovery#team-details)
- An action menu for [removing the application](management#removal)

Use the pagination controls at the bottom of the table to move between pages and to change how many applications are shown at a time.

:::info
If you do not see any applications yet, you either have not been added to a team or your teams have not created any applications. You must [belong to a team](../teams/management#adding-team-members) before you can create an application.
:::
