A quick and easy way to see if your flag's rules are evaluating to the values you expect them to is by using the 'Test run your feature flag' tool.

The tool will utilize all of your flag's rules and the context you provide in order to evaluate the flag just like as if your application were trying to evaluate it. It will also provide you with a reason as to why it evaluated to a specific variation.

The tool evaluates against an evaluation context that you provide. An optional date and time picker is available for testing rules with time based conditions.

## Log

Every action starting from the creation of the feature flag is logged as a log entry. For more on what the log includes, reference the [logs guide](../logs).

The 'Log' tab shows the same entries as the general logs page, scoped to this flag.
