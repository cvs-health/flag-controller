The default route of the feature flag UI is a list of feature flags. A switcher at the top of the page controls which flags the list shows:

- **My flags** (the default) - flags from your teams' applications
- **All flags** - flags across the organization's applications

Each of the feature flags in the list includes:

- The feature flag key which directs you to the feature flag details
- The application that owns the feature flag which directs you to the application details
- The date in which the flag was created
- The date in which the flag was last modified
- The [type](/docs/glossary#feature-flag-type) of flag
- The enabled or disabled state of the flag across the available [environments](/docs/glossary#environment)

## Finding a feature flag

The search field and the filters apply within the switcher scope you have selected. Searching **My flags** will not return flags from applications your teams do not own, so if you cannot find a flag, switch to **All flags** to search across the organization's applications. When a search in **My flags** comes back empty, the empty state links you directly to the same search in **All flags**.

The search field matches on flag name and/or application. The available filters are:

- **Creation date** - a start and end date range
- **Last modified date** - a start and end date range
- **Type** - `Boolean`, `Number`, `Text`, and/or `Object`
- **Enabled in** - `Development` and/or `Production`
- **Status** - `Archived only`

:::note
Archived flags are hidden from the list by default. Select the **Archived only** status filter to see them.
:::
